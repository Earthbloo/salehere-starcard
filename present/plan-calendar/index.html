Phase 1 · Star Profile

  • สมัครเป็น ST★R 8 ขั้น (คำถามที่แบรนด์ใช้เลือก + KYC)
  • KYC gate: รอตรวจ / ไม่ผ่าน / ผ่าน → ตราน้ำเงินข้างชื่อ
  • ฟอร์มลงทะเบียน: ชื่อ · Line ID · ที่อยู่
  • Wizard 13 หัวข้อ: ประเภท · ช่องทาง · หมวด · จังหวัด · เวลาว่าง · สัดส่วน · ข้อจำกัด · About + รูป/ผลงาน/วิดีโอ
  • หน้า Star Profile: วงแหวน % + เติมข้อมูลต่อ · กลุ่ม "เติมเมื่อถึงเวลา"
  • การ์ดช่องทาง: ผูกบัญชี · เรทราคา · Insight อัปโหลด screenshot
  • Banner ชวนสมัคร + คำถามแรกเป็น sheet
  • Star Card เก่าอยู่ท้ายหน้า ยังไม่แตะ
  • ฟิลด์ใหม่ creatorType ที่เหลือใช้ฟิลด์เดิม API

ออกแบบ Widget

  • ไล่ widget ทั้งหมดใน prototype → เลือกชุดที่จะทำจริง
  • แบบสุดท้ายต่อ widget: ขนาด · ช่องข้อความ · สีตาม theme การ์ด
  • กติกา Verified by Sale Here บนการ์ด (ตราติดทุกใบ ลบไม่ได้)
  • สเปก iOS/Android ให้ render ตรงกัน PARITY
  • โครง JSON ของการ์ด 1 ชุดใช้ทุก platform API

Phase 2 · ST★R Card

  • เลือก Template → แต่งการ์ด ข้อมูลดึงจาก Star Profile อัตโนมัติ

  • แก้ข้อความแบบ IG Story · ฟอนต์ไทยไม่มีหัว
  • ตรา Verified by Sale Here ติดทุกการ์ด
  • Export รูป + ใบรับรองท้ายการ์ด · ส่งลิงก์ · โหมดดู (โทร / ไปโซเชียล / ติดต่อ)
  • ST★R Insight: ใครมาดู + แจ้งเตือน
  • หน้าเปิดลิงก์การ์ด (ตอนนี้ลิงก์ 404) WEB
  • เก็บการ์ดเป็น JSON · render native · PNG สำรองสำหรับแชร์ API

Phase 3 · ตารางงาน ST★R

  • งาน Sale Here เข้าอัตโนมัติ แยกชัดจากงานทั่วไป (เห็นคนเดียว)
  • แจ้งเตือนก่อนวันลง / วันไปหน้างาน PUSH
  • เก็บงาน + ผูก campaign Sale Here API
