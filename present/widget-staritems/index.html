วิดเจ็ตแต่ละใบรอติ๊กถูกแถวไหน

ล็อกต่อวิดเจ็ตด้วยติ๊กถูกเดียวกับหน้า Star Profile: ใบนี้ปลดล็อกเมื่อแถวที่มีจุดทึบติ๊กเขียวครบ · ไล่ binding ของ spec ทั้ง ใบใน shared/WidgetSpecs แล้วตามว่า field นั้นมาจากข้อมูลของแถวไหน (salehere-ios + salehere-android · 8 พ.ย. 2569) · จุดทึบในตาราง = widget.requires ใน JSON แล้วทุกใบ · กติกาฝั่งแอป: shared/docs/STAR-CARD-LOCK.md

ต้องติ๊กถูก (ยังไม่ติ๊ก = ล็อก) ฿ ติ๊กถูกช่องทางของฉัน และต้องมีราคา (ป้าย "IG ฿1,000" ในแถว) ใช้ถ้ามี ไม่ล็อก 🔒 งานกับ Sale Hereไม่มีแถวใน Star Profile ล็อกจนมีงานที่รีวิวแล้วผ่าน Sale Here วางเมาส์บนหัวคอลัมน์ = ติ๊กถูกเมื่อไหร่ · การรับเงิน / ที่อยู่รับของ ไม่มีวิดเจ็ตไหนใช้

รูปในวิดเจ็ตมาจากไหน ถ้ายังไม่กรอก "เกี่ยวกับคุณ"

salehere-ios StarCardRenderContext.photo(slot:) → StarCardOwnerPhotos.url (Android ownerPhotoUrl ใช้กติกาเดียวกัน) · ไล่ทีละช่องรูป เจอที่ไหนก่อนใช้อันนั้น

  1. รูปที่เลือกในเครื่อง
    ระหว่างอัป หรือหลัง "จัดรูป" (Application Support/starcard-photos)
  2. รูปที่ใส่ให้ช่องนั้นเองจาก "คลังรูป"
    item.photos บนการ์ดใน server · ใส่ได้ทุกช่อง ไม่ต้องกรอกเกี่ยวกับคุณ
  3. รูปของเจ้าของ (ตอนผู้ใช้ไม่ได้เลือกรูปเอง)
    ช่อง 1–3: รูปครีเอเตอร์ ใน step เกี่ยวกับคุณ (profileImages · 3 ช่อง) วนตามจำนวนรูป → ไม่มีก็ใช้ avatar บัญชี (profileImageUrl) · ช่อง 4 ขึ้นไป: รูปผลงาน ใน step เกี่ยวกับคุณ (portfolio.images) วนตามจำนวนรูป → ไม่มีก็ว่าง ตัววาดไม่วาดอะไรในช่องนั้น (ไม่มีรูปตัวอย่างหรือ placeholder) · นับช่องเป็นรอบละ 12

สรุป: กรอกเกี่ยวกับคุณแล้ว ช่อง 1–3 = รูปครีเอเตอร์ · ช่อง 4+ = รูปผลงาน · ถ้ายังไม่กรอก ช่อง 1–3 จะยังได้ avatar บัญชี แต่ช่อง 4+ จะว่าง จนกว่าจะใส่รูปจากคลังรูปเอง · ตัวอย่าง: วิดเจ็ตรูปผลงาน (kitWorks*) ใช้ช่อง 1–6 ช่อง 1–3 จะได้ avatar เดียวกันทั้ง 3 ช่อง ส่วนช่อง 4–6 จะว่าง · ตอนนี้วิดเจ็ตหมวดรูป/โชว์เคสล็อกด้วย about อยู่แล้ว เลยวางเพิ่มจากถาดไม่ได้ แต่ถ้าวิดเจ็ตมากับ template ก็จะมีช่องว่างแบบนี้บนการ์ด · รูปในตารางเป็นภาพ render จาก iOS พร้อมข้อมูลตัวอย่าง (widget-catalog 4 พ.ย.) ไม่ใช่ตอนที่ช่องว่าง

จุดที่ต้องรู้ก่อนเปลี่ยนเป็นล็อกต่อวิดเจ็ต

  • ใช้ฟังก์ชันเดียวกับติ๊กถูกการ์ดใช้ StarCardOwner ส่วน Star Profile ใช้ StarProfileSnapshot คิดกันคนละที่ ต้องย้ายกฎไปไว้ที่เดียวให้ทั้งสองเรียก ไม่อย่างนั้นติ๊กเขียวแต่วิดเจ็ตยังล็อกจะกลับมาอีก
  • สัดส่วน: ติ๊กที่ 1 ค่า แต่การ์ดรอ 6 ค่าเลือกได้ 2 ทาง: วิดเจ็ตปลดล็อกที่ 1 ค่าแล้วโชว์เฉพาะค่าที่มี หรือให้ติ๊กขึ้นเมื่อครบ 6 ค่า
  • รูปช่อง 1–3 ไม่ต้องล็อกทั้งสองแพลตฟอร์มใช้ profileImages ก่อน ถ้าไม่มีก็ใช้ avatar บัญชีแทน รูปจึงไม่ว่าง · popVideoGlass/Paper ใช้แค่ช่อง 2 เลยไม่ต้องล็อก
  • about ของ server เข้มกว่าที่วิดเจ็ตต้องใช้มีแคปชันแล้วแต่ยังไม่อัปคลิป = about ยังเป็น false วิดเจ็ตแนะนำตัวจะล็อกต่อ ถ้าอยากให้ปลดเร็วกว่านี้ server ต้องแยก flag ย่อย (เช่น caption / portfolio)
  • เว็บไซต์ว่างได้แม้ contact = true12 ใบที่แสดงเว็บไซต์จะขึ้นคำใบ้ yourname.com ถ้าไม่ได้กรอก · ไม่มีวิดเจ็ตไหนอ่านอีเมล
  • เรทไม่มีแถวของตัวเองป้ายราคาอยู่ในแถวช่องทางของฉัน แต่ติ๊กถูกของแถวนั้นไม่รอราคา (server socials ไม่บังคับเรท) · วิดเจ็ตเรทจึงต้องเช็กราคาเพิ่ม (฿ ในตาราง) และปุ่มบนวิดเจ็ตพาไปขั้นผูกบัญชี
  • ชื่อในโค้ดยังไม่ตรงกับแถวiOS การ์ดใช้ชื่อหมวดถาด (profile, niche, intro …) · ควรใช้ชื่อแถวชุดเดียวกับ Star Profile (iOS StarTopic / Android StarProfileDataRowType) ทั้งใน JSON และโค้ด
