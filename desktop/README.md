# Sale Here STAR · Desktop

ทั้ง flow ของแอปจำลอง iOS (`StarCard/StarCard/Views/SaleHere`) วางใหม่สำหรับจอ desktop — ยกเว้นหน้า Star Card (คลัง · ห้องแต่ง · เทมเพลต)
ไม่มี build: `node desktop/serve.mjs` (พอร์ต 8796 · ไม่จำไฟล์) หรือ preview config `desktop`

กติกาของ flow (ลำดับคำถาม · เงื่อนไขผ่าน · ข้อความ) ถอดจาก `Model/StarFlow.swift` แบบ 1:1 อยู่ใน `js/flow.js` ไฟล์เดียว
หน้าจอแค่ "วาง" ต่างจากมือถือ เล่นแล้วจบที่ state เดียวกัน

| ไฟล์ | หน้าที่ |
|---|---|
| `js/flow.js` | state + กติกา (`F`) · กิจกรรมจำลอง · Insight · ตารางงาน · ขั้น/ฉากของ Lab |
| `js/ui.js` | ตัววาด · นำทาง + ปุ่ม Back · จุด hook ของ shell (`tapMain` `startWizard` `finishWizard` `openStarCard`) · ชิ้นส่วนร่วม |
| `js/screens.js` | หน้าแรก · กิจกรรม · โปรไฟล์ · ฟอร์มสมัคร · ตอบรับ · ส่งลิงก์ · ยืนยันตัวตน · dialog |
| `js/wizard.js` | wizard + ช่องกรอกทุกขั้น + dialog ช่องทาง/ข้อมูลผู้ติดตาม |
| `js/star.js` | Star Profile · การ์ดเกิด · ST★R Insight · ตารางงาน · Lab |
| `js/app.js` | action ของทุกปุ่ม · คีย์บอร์ด · ลากไฟล์ |

## สิ่งที่ต้องเท่ากับ iOS (อย่าแก้ฝั่งเดียว)

กติกาชุด salehere-ios (7 ต.ค. 2569 · `salehere-ios/docs/star-profile/STAR-FLOW-RULES.md`):

- STAR = มียศ (`starRank` · Lab สวิตช์ "STAR เก่า (มียศ STAR)" + ฉาก "STAR เก่า · ข้อมูลยังไม่ครบ (สถานะ C)") **หรือ** ครบ 8 ข้อ · สถานะ C = `needsStarInfo` · `starPct` = (8 − ขาด) ÷ 8 · ฉลองดู "ครบ 8 ข้อจริง" (`starComplete`) ไม่ใช่ยศ
- แถว Star Profile (`ROWS`) ลำดับแอปหลัก: ประเภทครีเอเตอร์ → … → ยืนยันตัวตนท้ายสุด · ไม่มีแถวเรทแล้ว (อยู่ในแถว "ช่องทางของฉัน") · `F.missingSteps(fromKey)` วนจากแถวที่แตะ · `F.fillMoreSteps`
- ชื่อช่องประบนการ์ด intro = `STEP.rowName` (ชื่อแถวเดียวกัน) · 1 ช่องต่อ 1 ข้อที่ขาด = N บนปุ่ม
- banner สูง 88 · ปุ่มขวาเป็นวงลูกศร ไม่มีข้อความ · ป้ายรอตรวจ/ไม่ผ่าน + พาไปหน้าสถานะ เฉพาะตอนเหลือแค่ยืนยันตัวตน (`kycOnlyBlocked`)
- ด่านสมัคร (`tapMain`): ครบ 8 → ฟอร์ม · เหลือแค่ KYC รอตรวจ/ไม่ผ่าน → หน้าสถานะ · อื่น ๆ → intro + wizard · จบ wizard: เพิ่งเป็น STAR → หน้า "คุณเป็น STAR แล้ว" · ครบ → ฟอร์ม · ยังขาด → Star Profile
- ช่องทางติดต่อ: ตรวจ format 3 ช่องรอบเดียว error ใต้ช่อง (ไม่ผูกกัน) · เติมเบอร์จากบัญชี/ที่อยู่ตอนเข้าหน้า (`wizOnShow`) · ที่อยู่ 7 ช่อง + รหัสไปรษณีย์ 5 หลัก
- ไม่มี toast ตอนจบ wizard ข้อเดียว · ✕ หน้า intro ออกเงียบ ๆ · dialog ออก = "ทำไปแล้ว x/y" เสมอ

- ชุดคำถาม: ลงทะเบียน = `registerSteps` (8 ข้อ) · จาก Star Profile = `applySteps` (10 หน้า) · ก่อนตอบรับ = ไม่แทรกอะไร (ที่อยู่อยู่ในฟอร์มสมัคร) · ก่อนเปิด Star Card = 3 ข้อ
- ไม่บังคับ = ไม่ถามซ้ำ (`insight`, `about`) · หน้ารวม: ช่องทาง+เรท+ข้อมูลผู้ติดตาม · แนะนำตัว+ผลงาน
- ข้อความเตือนของทุกขั้น · ขั้นต่ำ รูป 3 / ผลงาน 2 / คลิป 2 (≤100 MB) · สาย ≤5 · จังหวัด ≤3
- ได้เป็น STAR ฉลองครั้งเดียว ตอนจบ wizard หรือจบยืนยันตัวตน
- ฟอร์มสมัครกดส่งได้เมื่อมีที่อยู่ครบ 7 ช่อง + Line ID + ยอมรับเงื่อนไข (คำถามของแบรนด์ยังไม่บังคับ เหมือน iOS) · รหัสไปรษณีย์ → ตำบล (เลือก) → อำเภอ/จังหวัดเติมให้ (`ZIPBOOK` = ZipBook)
- ยืนยันตัวตนมี 4 สถานะ (ยังไม่ทำ · รอตรวจ · ตีกลับ · ผ่าน) และต้อง **ผ่าน** ก่อนส่งใบสมัคร — รอตรวจ/ตีกลับกดลงทะเบียน = หน้าสถานะ (`kycStatus`) · ขั้น KYC ใน wizard = การ์ดสถานะ + ปุ่ม "ปิดไว้ก่อน"
- ผลจากทีมงานมาถึง (Lab สลับสถานะ) = แจ้งเตือนมุมขวาบน: ผ่าน → พากลับฟอร์มสมัครของงานที่ค้าง (`pendingCampaign`) · ตีกลับ → หน้าสถานะ
- จบกล้อง: Lab "OCR ผ่าน" = ยืนยันการส่ง → เสร็จสมบูรณ์ (ผ่านทันที) · "AI ไม่ผ่าน" = เตือนภาพไม่ชัด → ฟอร์มกรอกมือ → ยืนยันการส่ง → ส่งคำขอสำเร็จ (รอตรวจ) · ตีกลับแล้วเข้าใหม่ = เปิดฟอร์มพร้อมการ์ดเหตุผลแดง
