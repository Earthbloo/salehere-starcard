# วันเวลาว่างรับงาน: รายการวัน + เลือกหลายวัน → salehere-ios

แทนหน้า `WzAvailabilityStep` แบบเดิม (วงกลมวัน + ชิปช่วงเวลา) ด้วย **รายการ 7 วัน + ช่องเวลาแบบ dropdown** และ **โหมดเลือกหลายวัน** สำหรับตั้งเวลาทีเดียวหลายวัน

- **ต้นแบบที่ผ่านแล้ว:** `present/availability-week/select-mode.html` (ในรีโปนี้)
  - ลิงก์: https://claude.ai/artifact/XNZd1yLVEn17YonUEjGSti
  - กดได้จริง มีปุ่ม "▶ ดูตัวอย่าง"
- **ข้อมูลไม่เปลี่ยน:** ยังเป็น `[CreatorAvailableDays: [CreatorTimeSlots]]` 4 ช่วงต่อวัน
- **API ไม่เปลี่ยน:** save ด้วย `interactor.saveAvailability(draft.availability)` เหมือนเดิม
- **ตัดสินแล้ว ห้ามเปลี่ยนเอง:** layout รายการ, โหมดแบบ "ซ่อนเวลา", ตำแหน่งปุ่มยกเลิก, motion น้อย

## 2. หน้าจอ 2 สถานะ

### 2.1 ปกติ

```
                                   ( เลือกหลายวัน )      ← capsule ขอบเทา ชิดขวา
┌──────────────────────────────────────────────────┐
│ จันทร์     [ 09.00–14.00, 17.00 เป็นต้นไป   ⌄ ] │
│ ──────────────────────────────────────────────── │   ← เส้นแบ่งเริ่มที่ตัวหนังสือ (inset 18)
│ อังคาร     [ 09.00–14.00, 17.00 เป็นต้นไป   ⌄ ] │
│ พุธ        [ 17.00 เป็นต้นไป                ⌄ ] │
│ …                                                │
│ อาทิตย์    [ ไม่ว่าง                         ⌄ ] │   ← "ไม่ว่าง" สีเทา ตัวบาง
└──────────────────────────────────────────────────┘
footer: [ ย้อนกลับ ] [ ถัดไป ]                          ← footer เดิมของ wizard
```

- แตะแถวไหน (ทั้งแถว) → เปิด sheet เวลาของวันนั้น 1 วัน

### 2.2 โหมดเลือกหลายวัน (หลังแตะ "เลือกหลายวัน")

```
เลือกทั้งหมด                              ( ยกเลิก )   ← ปุ่มเดิม เปลี่ยนเป็นพื้นถ่าน ตัวขาว
┌──────────────────────────────────────────────────┐
│ ☐ จันทร์                                          │   ← ช่องเวลาหลบไปทางขวาแล้วหายไป
│ ☑ พุธ                                (พื้น PK.pick) │
│ …                                                │
└──────────────────────────────────────────────────┘
footer: [        ตั้งเวลา 2 วัน        ]               ← ปุ่มเดียว เต็มความกว้าง
         ยังไม่เลือก = "เลือกวันก่อน" (จาง กดไม่ได้)
```

- **แตะแถว:** ติ๊กหรือเอาติ๊กออก (ทั้งแถวกดได้) ช่องเวลาไม่แสดงและไม่รับการกด
- **"เลือกทั้งหมด":** ติ๊กครบ 7 วัน ถ้าครบแล้วข้อความเปลี่ยนเป็น "ไม่เลือกเลย"
- **"ยกเลิก":** ออกจากโหมดและล้างที่ติ๊กไว้ อยู่ **ตำแหน่งเดียวกับปุ่ม "เลือกหลายวัน"**
  - ห้ามย้ายไปไว้ที่ footer: UAT บอกว่า "ปุ่มยกเลิกหายากมาก งง"
- **"ตั้งเวลา N วัน":** เปิด sheet ของวันที่ติ๊ก
- **ปุ่ม ‹ บนหัว:** ระหว่างอยู่ในโหมด ให้ออกจากโหมดก่อน แล้วอยู่หน้าเดิม ไม่ย้อนไปข้อก่อนหน้า

## 3. State (presenter)

```swift
// แทน `availabilityDay`
@Published var availSelecting = false                       // อยู่ในโหมดเลือกหลายวัน
@Published var availPicked: [GraphAPI.CreatorAvailableDays] = []   // วันที่ติ๊ก (เรียงตาม weekOrder ตอนใช้)
@Published var availSheet: AvailSheet?                      // sheet เวลา เปิดอยู่ = ไม่ nil
@Published var availFresh: Set<GraphAPI.CreatorAvailableDays> = []  // วันที่เพิ่งได้ค่าใหม่ (ขึ้นสีเขียวอ่อนแล้วจาง)

struct AvailSheet: Equatable {
    var days: [GraphAPI.CreatorAvailableDays]   // เรียงตาม StarAvailability.weekOrder
    var draft: [GraphAPI.CreatorTimeSlots]
    var multi: Bool                              // เปิดจากโหมดเลือก
}
```

**เปิด sheet:**
- ถ้าทุกวันใน `days` มีช่วงเวลาเหมือนกัน → `draft` = ช่วงเวลาชุดนั้น
- ถ้าไม่เหมือนกัน → `draft = []` และแสดงข้อความ mixed (ข้อ 5)

**กดปุ่มใน sheet (`applyAvail()`):** ทำทุกอย่างพร้อมกันในครั้งเดียว ห้ามหน่วงทีละวัน
1. เขียน `draft.availability[d] = allSlots.filter(draft.contains)` ทุกวันใน `days`
2. `availSheet = nil`
3. `availSelecting = false`, `availPicked = []`
4. `availFresh = Set(days)`

ออกจาก step หรือ `leave()` → reset ทั้ง 4 ค่า

## 4. รายการวัน (ไฟล์ `WzAvailabilityStep`)

### 4.1 การ์ดรายการ

| ส่วน | ค่า |
|---|---|
| พื้น | `.white` |
| มุม | 20 (`.continuous`) |
| ขอบ | 1pt `#ECEDEF` |
| เงา | `black 3%` y1 r2 + `black 10%` y8 r20 (−12 spread → ใน SwiftUI ใช้ `shadow(color: .black.opacity(0.06), radius: 10, y: 6)` ก็พอ) |
| เส้นแบ่งแถว | 1pt `#EFF0F2` เริ่มที่ x = 18 ถึงขอบขวา ไม่มีเส้นเหนือแถวแรก |

### 4.2 แถว

| ส่วน | ค่า |
|---|---|
| ความสูงขั้นต่ำ | 62 |
| padding | top 10 · trailing 12 · bottom 10 · leading 18 |
| ช่องติ๊ก (เฉพาะโหมดเลือก) | กว้าง 0 → 36 · กล่อง 22×22 มุม 7 · ขอบ 1.5 `PK.line2` · ติ๊กแล้ว = พื้น `PK.charcoal` + ✓ ขาว |
| ชื่อวัน | `.sh(15, .semibold)` `GL.ink` กว้างคงที่ 78 · ข้อความจาก `"STAR_DAY_\(d.rawValue.uppercased())".localized()` |
| ช่องเวลา | ยืดเต็มที่เหลือ · สูงขั้นต่ำ 42 · มุม 12 · พื้น `#F4F5F7` · padding 7/12/7/14 |
| ข้อความเวลา | `.sh(14, .medium)` `GL.ink` · ว่าง = "ไม่ว่าง" `.sh(14)` `PK.hint` |
| ลูกศร | chevron-down 14pt สี `PK.hint` ชิดขวาในช่อง |
| แถวที่ติ๊ก (โหมดเลือก) | พื้นทั้งแถว `PK.pick` |

### 4.3 ข้อความในช่องเวลา

ใช้ `StarAvailability.slotText(Set(slots), separator: ", ")` โดยเพิ่มพารามิเตอร์ `separator` ที่ค่าเริ่มต้นเป็น `" + "` เพื่อให้จุดอื่นที่เรียกอยู่ไม่เปลี่ยน

ตัวอย่างผลลัพธ์:
- ช่วงติดกันรวมเป็นช่วงเดียว: `09.00–14.00`
- ช่วงห่างกันคั่นด้วย `, `: `09.00–14.00, 17.00 เป็นต้นไป`
- ครบ 4 ช่วง: `ทุกช่วงเวลา`
- ว่าง: `""` → แสดง "ไม่ว่าง"

### 4.4 แถวหัวรายการ (เหนือการ์ด)

- **ฝั่งซ้าย:** "เลือกทั้งหมด" `.sh(14, .semibold)` ขีดเส้นใต้สี `PK.line2`
  - แสดงเฉพาะในโหมดเลือก (`opacity` 0 ↔ 1, `allowsHitTesting`)
- **ฝั่งขวา:** capsule `.sh(13, .semibold)` padding 14×6 กว้างขั้นต่ำ 104 ตัวหนังสือกลาง

| สถานะ capsule | ข้อความ | พื้น | ขอบ | ตัวหนังสือ |
|---|---|---|---|---|
| ปกติ | "เลือกหลายวัน" | ขาว | `PK.line2` | `GL.ink` |
| โหมดเลือก | "ยกเลิก" | `PK.charcoal` | `PK.charcoal` | ขาว |

## 5. Sheet เวลา

ใช้ `WzBottomPanel` ตัวเดิม (เหมือนวงล้อสัดส่วน) ใส่ใน `ZStack` ของ `StarWizardMainView` คู่กับ `bodyPick`

```swift
if presenter.availSheet != nil {
    WzBottomPanel(close: { presenter.availSheet = nil }) { WzAvailSheet(presenter: presenter) }
}
// .animation(Motion.settle, value: presenter.availSheet)
```

เนื้อหาเรียงจากบนลงล่าง:
1. **หัวข้อ** `.sh(18, .heavy)`
   - 1 วัน (เปิดจากแถว): ชื่อวันเต็ม เช่น "อาทิตย์"
   - หลายวัน (เปิดจากโหมดเลือก): "ตั้งเวลา N วัน"
2. **แถววงกลม 7 วัน** (เฉพาะหลายวัน, ดูอย่างเดียวกดไม่ได้)
   - วงกลมเต็มความกว้าง 7 ช่อง gap 6 ตัวย่อจาก `StarAvailability.shortName`
   - วันที่เลือก = พื้น `PK.charcoal` ตัวขาว · วันอื่น = พื้น `PK.fieldFill` ตัว `PK.hint`
3. **ข้อความ mixed** (เมื่อวันที่เลือกมีช่วงเวลาไม่เหมือนกัน) `.sh(13)` `PK.muted`: "วันที่เลือกตั้งเวลาไว้ไม่เหมือนกัน เวลาที่เลือกตรงนี้จะใช้แทนทั้งหมด"
4. **ตัวเลือก 5 แถว:** 4 ช่วงจาก `StarAvailability.slotLabel` + "ทุกช่วงเวลา"
   - แต่ละแถว = ช่องติ๊ก 22 + ข้อความ `.sh(15)` padding แนวตั้ง 12
   - เส้นแบ่ง `PK.line` ส่วนเส้นเหนือ "ทุกช่วงเวลา" ใช้ `PK.line2`
   - "ทุกช่วงเวลา": ถ้ายังติ๊กไม่ครบ 4 → ติ๊กครบ 4 · ถ้าครบอยู่แล้ว → ล้างทั้งหมด
   - หน้านี้ใช้ช่องติ๊ก (ต่างจาก `WzChip` ที่ไม่มี checkbox) เพราะเป็นรายการเลือกหลายข้อในแผงล่าง ตรงตามต้นแบบ
5. **ปุ่มหลัก** `PKPrimaryButton` เต็มความกว้าง
   - 1 วัน: "ตกลง" (`STAR_WZ_OK`)
   - หลายวัน: "ใช้กับ N วัน"
   - เลือกไม่ติ๊กอะไรเลยแล้วกดได้ = ตั้งวันนั้นเป็น "ไม่ว่าง"

แตะพื้นมืดหรือปัดลง = ปิด sheet โดยไม่บันทึก และยังอยู่ในโหมดเลือกเหมือนเดิม

## 6. Motion (น้อยเท่าที่จำเป็น)

| จังหวะ | ทำอะไร | ค่า |
|---|---|---|
| เข้า/ออกโหมด | ช่องติ๊กกว้าง 0→36 และจาง→ชัด · ช่องเวลาเลื่อนขวา 24pt + จางหาย · capsule เปลี่ยนสี · footer สลับปุ่ม | `withAnimation(Motion.snap)` ≈ 240ms |
| เปิด/ปิด sheet | `WzBottomPanel` ตัวเดิม (เลื่อนขึ้นจากล่าง + จาง) | `Motion.settle` |
| กดตกลง | ปิด sheet + ออกโหมด **พร้อมกัน** ค่าใหม่อยู่ในช่องแล้วตอนช่องกลับเข้ามา · ช่องของวันที่เปลี่ยนขึ้น `GL.greenTint` ทันที แล้วจางกลับ `#F4F5F7` | จาง 0.6s `.easeOut` |
| ติ๊กวัน / ตัวเลข "N วัน" | **ไม่มี motion** ห้ามเด้งหรือ scale | ใส่ `.transaction { $0.animation = nil }` ที่ข้อความปุ่ม |

ทางทำสีเขียวจาง: ตั้ง `availFresh = Set(days)` แล้วถัดไปหนึ่ง runloop (`DispatchQueue.main.async`) สั่ง `withAnimation(.easeOut(duration: 0.6)) { availFresh = [] }` ช่องเวลาใช้ `availFresh.contains(d) ? GL.greenTint : Color(hex F4F5F7)` เป็นพื้น

Haptics: `Haptics.impact(.light)` ตอนแตะแถว เข้า/ออกโหมด และกดตกลง

Reduce Motion: ถ้า `@Environment(\.accessibilityReduceMotion)` เป็นจริง ใช้ `nil` animation (สีเขียวยังขึ้นแต่ไม่จาง)

## 8. กฎเดิมที่ต้องคงไว้

- **ปุ่ม "ถัดไป":** ยัง validate `draft.anyAvailability` เหมือนเดิม ถ้าไม่ผ่านขึ้น `STAR_WZ_ERR_AVAILABILITY` ("เลือกช่วงที่ว่างอย่างน้อย 1 ช่อง")
- **footer ปกติ (ย้อนกลับ + ถัดไป / ข้าม):** ไม่เปลี่ยน สลับไปเป็นปุ่มเดียวเฉพาะตอน `step == .availability && presenter.availSelecting`
- **`StarProfile.availabilitySummary`:** ไม่เปลี่ยน เป็นสรุปหน้าโปรไฟล์ คนละที่กับหน้านี้

## 9. เช็กก่อนส่ง (เทียบกับต้นแบบ HTML)

- [ ] แตะ "อาทิตย์" → sheet ชื่อ "อาทิตย์" → ติ๊ก 09.00–12.00 → ตกลง → แถวอาทิตย์เป็น "09.00–12.00" และขึ้นสีเขียวอ่อนแล้วจาง
- [ ] เลือกหลายวัน → ช่องเวลาหายหมด เหลือชื่อวัน + ช่องติ๊ก · capsule ขวาบนเป็น "ยกเลิก" พื้นถ่าน · footer เหลือ "เลือกวันก่อน" (จาง)
- [ ] ติ๊ก ส, อา → ปุ่มเป็น "ตั้งเวลา 2 วัน" ตัวเลขไม่เด้ง
- [ ] ตั้งเวลา 2 วัน → sheet "ตั้งเวลา 2 วัน" วงกลม ส อา ทึบ → ทุกช่วงเวลา → "ใช้กับ 2 วัน" → ออกโหมดทันที ส/อา = "ทุกช่วงเวลา"
- [ ] ติ๊ก จ (09.00–14.00, 17.00) กับ พ (17.00) → เปิด sheet → ขึ้นข้อความ mixed และไม่มีช่วงไหนติ๊กไว้ก่อน
- [ ] เลือกทั้งหมด → 7 วัน · ข้อความกลายเป็น "ไม่เลือกเลย"
- [ ] ยกเลิก (ปุ่มขวาบน) → กลับหน้าปกติ ไม่มีวันไหนเปลี่ยน
- [ ] ‹ บนหัวระหว่างอยู่ในโหมด → ออกจากโหมด ยังอยู่ข้อนี้
- [ ] แตะพื้นมืดตอน sheet เปิด → ปิด sheet ไม่บันทึก
- [ ] ถัดไป → save ผ่าน `saveAvailability` ตามเดิม · ไม่ว่างเลยทั้งสัปดาห์ = error เดิม
- [ ] เปิด Reduce Motion → ไม่มีการเลื่อนหรือจาง ทุกอย่างยังใช้งานได้
